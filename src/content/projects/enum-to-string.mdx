I recently ran into a really nice way to convert an enum to a string in Unreal Engine!
No more manual string conversion or switch statements. This method is super clean and easy to use.

```c++
StaticEnum<EYourEnumType>()->GetDisplayValueAsText(YourEnumValue).ToString();
```
