If you're already using UBA and have it configured, enable the `UBA Controller` plugin and

<Img src="projects/distributed-shader-compilation/UnrealEditor-Win64-DebugGame_rdQa1AXf4G.png" alt="Image" />

And add the following to your DefaultEngine.ini:

```ini
[UbaController]
Enabled = true
```
