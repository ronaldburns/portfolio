If you're already using UBA and have it configured, enable the `UBA Controller` plugin and 

![Image](https://r2-portfolio.ronaldburns.dev/projects%2Fdistributed-shader-compilation%2FUnrealEditor-Win64-DebugGame_rdQa1AXf4G.png)

And add the following to your DefaultEngine.ini:

```ini
[UbaController]
Enabled = true
```
