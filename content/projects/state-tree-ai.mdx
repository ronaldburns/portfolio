## Experimenting with State Tree

I've been testing the limits of state tree, seeing if it's possible to fully drive AI using it.
I'm very pleased with the results I've achieved.
With the ability to **finally** output data from a task, and use that data with sibilings, it really opens the gates for what's possible with state tree.
Not to mention Epic's new EQS Query node. I'm excited to see their implementation of it is the exact same as how I was able to implement it a few months ago.
